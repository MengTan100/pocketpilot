PocketPilot

用手机指挥电脑上的 DeepSeek Harness：手机端 App + 电脑端 DSH 插件，扫码配对，共享同一个真实会话。

Drive DeepSeek Harness on your computer from your phone: an Android app plus a DSH plugin, paired by QR code, sharing one real session.

1手机端：安装 AppPhone: install the app

下载上面的 app-release.apk 直接安装。首次启动会让你阅读并同意免责声明。

Download app-release.apk above and install it. On first launch it asks you to read and accept the disclaimer.

扫二维码配对

Pair by QR code

电脑端显示二维码，手机扫一下就连上，不用手输地址。

The desktop shows a QR code; scan it and you are connected — no manual address typing.

也可手动配对

Or pair manually

同一局域网内可手输地址与配对码；异地可用隧道。

On the same LAN you can type the address and pairing code; use a tunnel when remote.

Auto reconnect

断线自动重连并显示连接状态，时钟偏差自动校正。

Reconnects automatically with a status indicator, and corrects clock skew.

2电脑端：安装 DSH 插件Desktop: install the DSH plugin

直接填仓库地址安装，装好会自动启用（dsh plugin 是 pnpm 的封装，装完会把声明了 dsh.bundle 的依赖并入 profile 的 layers）：

Install straight from the repository address; it is enabled automatically (dsh plugin wraps pnpm and folds any dependency declaring dsh.bundle into the profile's layers):

dsh plugin add github:MengTan100/pocketpilot

若提示 profile 不对，补上你的 profile 名，例如：dsh plugin --profile desktop add github:MengTan100/pocketpilot

If it complains about the profile, pass yours explicitly: dsh plugin --profile desktop add github:MengTan100/pocketpilot

装不上时（网络不稳 / 想离线）

If that fails (flaky network / you prefer offline)

下载发布页里的 dsh-plugin-phone-bridge-0.4.0.zip，解压后用本地路径安装：

Download dsh-plugin-phone-bridge-0.4.0.zip from the release page, unzip it, then install by local path:

dsh plugin add "C:\你解压的位置\dsh-plugin-phone-bridge"

插件界面文字跟随系统 / DSH 的语言设置（简体中文 / English）。

The plugin UI follows your system / DSH language (Simplified Chinese / English).

3启动桥接并配对Start the bridge and pair

在电脑上运行桥接（首次会显示配对二维码）：

Run the bridge on your computer (it shows the pairing QR code on first run):

pc\start-bridge.bat

然后在 DSH 侧栏底部点「手机连接 / Phone link」，用手机扫描弹窗里的二维码即可。

Then click “Phone link” at the bottom of the DSH sidebar and scan the QR code in the dialog with your phone.
